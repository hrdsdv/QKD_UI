# 🌐 Настройка IP удаленного сервера через веб-интерфейс

## ✅ Что было добавлено

Теперь вы можете настраивать IP-адрес удаленного сервера прямо через веб-интерфейс, без необходимости редактировать код или config.py!

## 🎯 Как использовать

### Шаг 1: Запустите серверы

Запустите оба сервера как обычно:
- **ПК1 (server_user_1):** `python server_user_1/app.py`
- **ПК2 (server_user_2):** `python server_user_2/app.py`

### Шаг 2: Откройте веб-интерфейс

- **ПК1:** http://127.0.0.1:5000
- **ПК2:** http://127.0.0.1:5001

### Шаг 3: Настройте IP-адрес

1. Войдите в систему (любой пользователь)
2. В правом верхнем углу нажмите кнопку **"Настройки сети"**
3. В открывшемся окне введите IP-адрес удаленного сервера:
   - **На ПК1:** введите IP ПК2, например: `http://172.16.111.53:5001`
   - **На ПК2:** введите IP ПК1, например: `http://172.16.111.52:5000`
4. Нажмите **"Сохранить"**

### Шаг 4: Готово!

IP-адрес сохраняется в базе данных и будет использоваться для всех запросов к удаленному серверу.

## 📝 Важные замечания

1. **Формат IP-адреса:** 
   - Можно вводить с `http://` или без него (автоматически добавится)
   - Примеры: `172.16.111.53:5001` или `http://172.16.111.53:5001`

2. **Автоматическое создание таблицы:**
   - При первом запуске сервера таблица `settings` создается автоматически
   - Начальное значение берется из `config.py`

3. **Изменения применяются сразу:**
   - После сохранения новый IP используется для всех новых запросов
   - Старые запросы продолжают использовать предыдущий IP

4. **Проверка подключения:**
   - После настройки попробуйте отправить тестовое сообщение через чат
   - Если есть ошибки, проверьте:
     - Правильность IP-адреса
     - Открыты ли порты в брандмауэре
     - Запущен ли удаленный сервер

## 🔧 Технические детали

- IP-адрес сохраняется в таблице `settings` в базе данных
- Ключ: `remote_server_url`
- Значение используется функцией `get_remote_server_url()` вместо `REMOTE_SERVER_B`/`REMOTE_SERVER_A`
- Все запросы к удаленному серверу используют IP из БД

## 🚀 Преимущества

- ✅ Не нужно редактировать код
- ✅ Работает после сборки в exe
- ✅ Можно менять IP без перезапуска сервера (для новых запросов)
- ✅ Удобный веб-интерфейс
- ✅ Сохранение в БД (надежно)
